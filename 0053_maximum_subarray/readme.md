## Задача

> Given an integer array `nums`, find the subarray with the largest sum, and return its sum.

Найти подмассив с максимальной суммой и вернуть эту сумму.

**Ссылка:** [leetcode.com/problems/maximum-subarray](https://leetcode.com/problems/maximum-subarray/)

---

## Инженерка

### Что за задача

Есть массив целых чисел (в том числе отрицательных). Нужно найти непрерывный подмассив, сумма элементов которого максимальна.

### Первая мысль (наивное решение)

Перебрать все возможные подмассивы двумя вложенными циклами, считать сумму каждого и запоминать максимум. Работает, но `O(n²)` — при больших массивах слишком медленно.

### Оптимальное решение — алгоритм Кадана

Ключевая идея: в каждой точке мы делаем один выбор — **продолжить предыдущий подмассив** или **начать новый с текущего элемента**.

1. Инициализируем `currentSum` и `maxSum` первым элементом
2. Для каждого следующего элемента `v`:
   - `currentSum = max(v, currentSum + v)` — либо начинаем заново, либо продолжаем
   - `maxSum = max(currentSum, maxSum)` — обновляем глобальный максимум
3. Возвращаем `maxSum`

### Почему `max(v, currentSum + v)`

Если `currentSum` отрицательный, то добавление его к `v` только уменьшит результат. Выгоднее бросить накопленный «балласт» и начать подмассив заново с `v`. Это и есть суть алгоритма Кадана: не тащить отрицательный хвост дальше.

### Почему O(1) памяти

Не нужен никакой дополнительный массив — только две переменные: текущая сумма и максимальная. Один проход, никаких структур данных.

## Решение

```go
package main

import "fmt"

func maxSubArray(nums []int) int {
	currentSum := nums[0]
	maxSum := nums[0]
	for _, v := range nums[1:] {
		currentSum = max(v, currentSum+v)
		maxSum = max(currentSum, maxSum)
	}
	return maxSum
}

func main() {
	fmt.Println(maxSubArray([]int{-2, 1, -3, 4, -1, 2, 1, -5, 4}))
	fmt.Println(maxSubArray([]int{1}))
	fmt.Println(maxSubArray([]int{5, 4, -1, 7, 8}))
}
```

| Вход                        | Оптимальный подмассив | Результат |
| --------------------------- | --------------------- | --------- |

| `[5,4,-1,7,8]`              | `[5,4,-1,7,8]`        | `23`      |

Трассировка для `[-2,1,-3,4,-1,2,1,-5,4]`:

| Шаг | `v`  | `currentSum`        | `maxSum` |
| --- | ---- | ------------------- | -------- |
| 0   | —    | `-2`                | `-2`     |
| 1   | `1`  | `max(1, -1) = 1`    | `1`      |
| 2   | `-3` | `max(-3, -2) = -2`  | `1`      |
| 3   | `4`  | `max(4, 2) = 4`     | `4`      |
| 4   | `-1` | `max(-1, 3) = 3`    | `4`      |
| 5   | `2`  | `max(2, 5) = 5`     | `5`      |
| 6   | `1`  | `max(1, 6) = 6`     | `6`      |
| 7   | `-5` | `max(-5, 1) = 1`    | `6`      |
| 8   | `4`  | `max(4, 5) = 5`     | `6`      |

|            | Сложность | Объяснение                                                    |
| ---------- | --------- | ------------------------------------------------------------- |
| **Время**  | `O(n)`    | Один проход по массиву, каждый элемент обрабатывается один раз |
| **Память** | `O(1)`    | Только две переменные, независимо от размера массива           |

---

## Что применял

- **Алгоритм Кадана** — классика для задач на максимальный подмассив; локальное жадное решение (начать заново или продолжить) даёт глобальный оптимум
- **Инициализация первым элементом** — корректно обрабатывает массивы из одних отрицательных чисел: ответ не `0`, а наименее отрицательный элемент
- **Встроенная функция `max`** — доступна в Go 1.21+, устраняет необходимость писать вспомогательную функцию
- **Ранний отказ от балласта** — если `currentSum` уходит в минус, алгоритм не тащит его дальше, сбрасывая к текущему элементу
