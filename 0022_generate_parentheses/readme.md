## Задача

> Given `n` pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

**Ссылка:** [leetcode.com/problems/generate-parentheses](https://leetcode.com/problems/generate-parentheses/)

---

## Инженерка

### Что за задача

Сгенерировать все строки длины `2n`, состоящие из `(` и `)`, которые являются валидными (каждая закрывающая скобка имеет пару, и порядок не нарушен). Задача на перебор — нужны не все строки, а только допустимые ветки построения.

### Первая мысль (наивное решение)

Сгенерировать все `2^(2n)` комбинаций `(` и `)`, и для каждой проверить валидность (как в [020 · Valid Parentheses](../0020_valid_parentheses/readme.md)). Работает, но избыточно — большая часть комбинаций отбрасывается уже на первых символах.

### Оптимальное решение — backtracking с отсечением

Строим строку посимвольно и не даём ей стать невалидной заранее — отсекаем плохие ветки сразу, а не после полной генерации.

Два счётчика: `open` — сколько `(` уже поставили, `close` — сколько `)` уже поставили.

1. Можем поставить `(`, если `open < n` (открывающих ещё не исчерпан лимит)
2. Можем поставить `)`, только если `close < open` (нельзя закрыть то, что не было открыто)
3. Когда длина строки дошла до `2n` — строка валидна по построению, добавляем в результат

### Почему именно так

Условие `close < open` — это и есть инвариант валидности скобок, перенесённый прямо в условие генерации. Вместо «сгенерировать и проверить» используется «генерировать только то, что не сломается». Дерево перебора автоматически содержит только корректные строки.

### Рекурсивный замыкание (closure) вместо отдельной функции

`backtrack` объявлена как переменная (`var backtrack func(...)`) и переопределена ниже — стандартный приём в Go для рекурсивных closures, которым нужен захват внешних переменных (`res`, `n`) без передачи их параметрами.

## Решение

```go
package main

import "fmt"

func main() {
	fmt.Println(generateParenthesis(3))
}

func generateParenthesis(n int) []string {
	res := make([]string, 0, 2*n)
	var backtrack func(cur string, open, close int)

	backtrack = func(cur string, open, close int) {
		if len(cur) == 2*n {
			res = append(res, cur)
			return
		}
		if open < n {
			backtrack(cur+"(", open+1, close)
		}
		if close < open {
			backtrack(cur+")", open, close+1)
		}
	}

	backtrack("", 0, 0)
	return res
}
```

## Разбор на примерах

Для `n = 2` дерево перебора (отсечённые ветки не показаны):

| Шаг      | `cur`  | `open` | `close` | Доступные ходы              |
| -------- | ------ | ------ | ------- | ---------------------------- |
| start    | `""`   | 0      | 0       | только `(` (close < open ложно) |
| 1        | `"("`  | 1      | 0       | `(` или `)`                  |
| 2a       | `"(("` | 2      | 0       | только `)` (open == n)       |
| 2a → 3   | `"(()"` | 2     | 1       | только `)`                   |
| 2a → 4   | `"(())"` | 2    | 2       | длина == 2n → **результат**  |
| 2b       | `"()"` | 1      | 1       | только `(`                   |
| 2b → 3   | `"()("` | 2     | 1       | только `)`                   |
| 2b → 4   | `"()()"` | 2    | 2       | длина == 2n → **результат**  |

Итог: `["(())", "()()"]` — ровно 2 комбинации (что совпадает с числом Каталана `C₂ = 2`).

## Сложность

|            | Сложность       | Объяснение                                                                                 |
| ---------- | --------------- | ------------------------------------------------------------------------------------------- |
| **Время**  | `O(4ⁿ/√n)`       | Столько валидных комбинаций существует (n-ое число Каталана); каждая строится за `O(n)`     |
| **Память** | `O(4ⁿ/√n)`       | Результат хранит все валидные строки; глубина рекурсии при этом всего `O(n)`                |

---

## Что применял

- **Backtracking с отсечением (pruning)** — условия `open < n` и `close < open` не дают зайти в невалидную ветку, поэтому не нужна постфактум-проверка готовой строки
- **Перенос инварианта валидности в условие генерации** — то же правило, что в [020 · Valid Parentheses](../0020_valid_parentheses/readme.md) (`close` не может обогнать `open`), но используется для построения, а не для проверки
- **Рекурсивная closure** — `var backtrack func(...)` + переопределение ниже, чтобы захватить `res` и `n` без лишних параметров
