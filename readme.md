Решения задач с LeetCode на Go.

Каждое решение содержит структурированный разбор: анализ задачи, обоснование подхода, оценку сложности и ключевые концепции.


## Структура папки задачи

```
1. Two Sum/
├── README.md       # Разбор задачи
└── main.go     # Реализация
```

Каждый `README.md` внутри папки задачи содержит следующие разделы:

**Задача** — формулировка и ссылка на LeetCode

**Инженерка** — три блока:
- `Что за задача` — суть своими словами
- `Наивное решение` — первая очевидная идея и почему она плоха
- `Оптимальное решение` — финальный подход с пошаговым объяснением

**Решение** — код на Go

**Сложность** — таблица Time / Space с объяснением

**Что применял** — конкретные паттерны, трюки и особенности языка использованные в решении

**Темы** — теги с темами
