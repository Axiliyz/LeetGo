## Задача

> You are given the heads of two sorted linked lists list1 and list2. Merge the two lists into one sorted list. The list should be made by splicing together the nodes of the two lists. Return the head of the merged linked list.

Даны два отсортированных связных списка. Нужно слить их в один отсортированный список. Узлы двух исходных списков должны остаться в новом списке (не копировать значения, а переиспользовать узлы, если возможно).

**Ссылка:** [leetcode.com/problems/merge-two-sorted-lists](https://leetcode.com/problems/merge-two-sorted-lists/)

---

## Инженерка

### Как додумался до решения

Прогнал на примере `[1, 3, 4]` и `[1, 2, 4, 6, 7, 8, 11, 13, 14, 16, 19, 22]`.

Первая мысль — идём по обоим спискам одновременно, сравниваем узлы, выбираем меньший и добавляем в результат. Когда один список закончится — присоединяем весь оставшийся хвост другого списка.

Ключевая мысль: **можно пройти по обоим спискам за один проход, используя два указателя, и одновременно строить результирующий список.**

Алгоритм:
- Два указателя `i1` и `i2` стартуют с голов обоих списков
- На каждом шаге берём меньший элемент и двигаем соответствующий указатель
- Когда один список кончается — присоединяем весь остаток другого

`O(n + m)` времени, где n и m — длины списков.

---

### Решение

Идём параллельно по обоим спискам. На каждом шаге сравниваем значения и берём узел с меньшим значением.

```go
func mergeTwoLists[T cmp.Ordered](list1 *LinkedList[T], list2 *LinkedList[T]) *LinkedList[T] {
	res := NewLinkedList[T]()
	i1 := list1.Head
	i2 := list2.Head
	
	// Основной цикл: пока оба списка не пусты
	for i1 != nil && i2 != nil {
		if i1.Val < i2.Val {
			res.Append(i1.Val)
			i1 = i1.Next
		} else {
			res.Append(i2.Val)
			i2 = i2.Next
		}
	}

	// Присоединяем оставшиеся узлы
	if i1 != nil {
		res.Tail.Next = i1
		res.Tail = list1.Tail
	} else if i2 != nil {
		res.Tail.Next = i2
		res.Tail = list2.Tail
	}
	
	return res
}

func main() {
	arr1 := []int{1, 3, 4}
	arr2 := []int{1, 2, 4, 6, 7, 8, 11, 13, 14, 16, 19, 22}
	l1 := NewLinkedList[int]()
	l2 := NewLinkedList[int]()
	
	for _, v := range arr1 {
		l1.Append(v)
	}
	for _, v := range arr2 {
		l2.Append(v)
	}

	res := mergeTwoLists(l1, l2)
	res.String()  // 1->1->2->3->4->4->6->7->8->11->13->14->16->19->22
}
```

## Сложность

|            | Сложность | Объяснение                                                        |
| ---------- | --------- | ----------------------------------------------------------------- |
| **Время**  | `O(n+m)`  | Проходим каждый узел ровно один раз: n узлов из list1 и m из list2 |
| **Память** | `O(n+m)`  | Создаём новый список с n+m узлами (или O(1) если переиспользуем)  |

---

## Эволюция решения

| Подход                                    | Время    | Память   |
| ----------------------------------------- | -------- | -------- |
| Два указателя с созданием новых узлов     | `O(n+m)` | `O(n+m)` |
| Два указателя с переиспользованием узлов* | `O(n+m)` | `O(1)`   |

*В текущей реализации создаются новые узлы, но можно оптимизировать, не создавая новые узлы и напрямую переиспользуя узлы из исходных списков.

---

## Что применял

- **Два указателя** — классический паттерн для работы со списками: идём синхронно по обоим спискам
- **Сравнение и выбор** — на каждом шаге выбираем меньший элемент
- **Переиспользование хвоста** — когда один список закончился, присоединяем весь хвост другого одной операцией
- **Обработка краевых случаев** — пустые списки, списки разных длин
